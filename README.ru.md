# inline-notes

**Ревью ответов Claude по строкам — как ревью пулреквеста.**

`/fb` открывает ответ в панели рядом с диалогом. Вы идёте по строкам и оставляете комментарии к строке или диапазону,<br>
а одна клавиша отправляет все комментарии обратно Claude одним промптом.

## Зачем

На длинный ответ Claude редко хочется ответить одной фразой. Обычно набирается десяток мелких замечаний: «этот шаг лишний», «а какой TTL?», «объедини эти два». Если писать их в промпт, строки приходится цитировать руками, и легко забыть, что уже сказано. `inline-notes` даёт указать прямо на строку, как в инструментах код-ревью, и передаёт Claude аккуратный нумерованный список, где у каждого комментария есть строки, к которым он относится.

## Возможности

- **Комментарии к строке и к диапазону.** Комментарий можно оставить на любой строке, а `v` сначала выделяет диапазон.
- **Два вида.** Исходные строки с номерами или ответ, отрисованный как markdown (`m`), с таблицами и блоками кода. В этом виде курсор ходит по блокам.
- **Страница в браузере.** `w` открывает ревью в браузере во всю ширину, текст набран шрифтом для чтения. Комментарий оставляется кликом или протяжкой по номерам строк, а «Скопировать промпт» кладёт в буфер обмена тот же промпт.
- **Один промпт обратно.** `s` собирает все комментарии вместе с цитатами строк в один промпт в поле ввода. Проверьте его, при желании вставьте скриншот и нажмите Enter. `/fb --send` отправляет сразу.
- **Всё с клавиатуры.** Клавиши идут в панель сразу после `/fb`, кликать не нужно. `j`/`k` и стрелки двигают курсор, `Enter` открывает комментарий. Работает и на русской раскладке.
- **В стиле Claude Code.** Акценты берутся из вашей темы Claude Code, тёмный или светлый фон панели — по ней же.
- **Ничего не теряется.** Если поле ввода не может принять комментарии (например, открыт диалог), они остаются в ревью. Повторный `/fb` не выбросит ревью, в котором есть комментарии.

## В браузере

Как ни расширяй панель, Claude Code оставляет диалогу 24 колонки. Если ответу нужно больше места, нажмите `w`: то же ревью откроется веб-страницей, с удобной для чтения шириной строки.

<img src="assets/web-demo.gif" alt="Ревью в браузере: протяжка по номерам строк и комментарий к блоку кода, переключение на отрисованный markdown, копирование промпта" width="100%">

Нажмите на номер строки или протяните по нескольким и напишите комментарий под ними. Клавиши те же, что в панели (`j`/`k`, `v`, `Enter`, `e`, `d`, `n`, `m`), а `s` или «Скопировать промпт» кладут промпт в буфер обмена. Вставьте его в Claude Code через ⌘V и нажмите Enter. Комментарии, оставленные в панели, переезжают на страницу, а оставленные на странице переживают её перезагрузку.

## Установка

В поле ввода Claude Code в терминале сначала добавьте маркетплейс, затем установите из него плагин:

```
/plugin marketplace add DaniilMats/inline-notes
/plugin install inline-notes@inline-notes
```

Нажмите Enter: плагин включится в пользовательской области, то есть во всех сессиях. Работает сразу.

<details>
<summary>Из shell или в desktop-приложении</summary>

Из shell:

```
claude plugin marketplace add DaniilMats/inline-notes

```

В desktop-приложении `/plugin` не работает. Нажмите **+** рядом с полем ввода, затем **Plugins** → **Add marketplace**, введите `DaniilMats/inline-notes` и нажмите **Add plugin**.

## Использование

| Команда | Что делает |
| --- | --- |
| `/fb` | Ревью последнего ответа или возврат к открытому ревью |
| `/fb N` | Ревью ответа номер N. После каждого ответа есть серая строка `↳ /fb N` |
| `/fb --send` | `s` отправляет комментарии сразу, а не кладёт их в поле ввода |

### Клавиши

| Клавиша | Действие |
| --- | --- |
| `j` / `k`, `↓` / `↑` | Следующая / предыдущая строка (в рендере — блок) |
| `g` / `G` | В начало / в конец |
| `ctrl+d` / `ctrl+u` | Страница вниз / вверх |
| `v` | Начать или снять выделение диапазона |
| `Enter` | Комментарий к строке или диапазону |
| `e` / `d` | Править / удалить комментарий на строке |
| `n` / `N` | Следующий / предыдущий комментарий |
| `m` | Переключить исходник и отрисованный markdown |
| `f` | Панель на весь экран и обратно |
| `w` | Открыть ревью в браузере |
| `s` | Комментарии в поле ввода |
| `q` | Закрыть ревью (с комментариями — двойным нажатием) |
| `?` | Все клавиши |
| `Esc` | Вернуться в поле ввода. Ревью остаётся: `/fb` или клик возвращают к нему |

В комментарии `Enter` сохраняет текст, а `Enter` в пустом комментарии отменяет его.

Работает и мышь: клик ставит курсор на строку (в рендере — на блок), второй клик туда же открывает комментарий, а клик по комментарию открывает его на правку. В рендере высоты блоков оцениваются, поэтому ближе к концу длинного ответа клик может попасть в соседний блок; подсветка покажет, какой выбран, до того как вы начнёте комментарий.

## Как это устроено

`inline-notes` — плагин Claude Code на function hooks. `/fb` читает ответы сессии, открывает панель и рисует в ней ревьюер как `Client`-модуль. Этот модуль читает клавиши напрямую, поэтому русская раскладка ведёт к тем же командам. Клавиатуру держит поле ввода нулевой высоты, так что кликать не нужно. Оно стоит на маркере `▌` активной строки или в точке набора комментария, поэтому курсор терминала не убегает в угол. По `s` комментарии превращаются в один промпт с цитатами пронумерованных строк.

Состояние ревью хранится в состоянии плагина в сессии, поэтому если закрыть панель через `Esc`, ничего не пропадёт.

По `w` плагин записывает [`web/review.html`](web/review.html) с ревью внутри во временную папку и открывает его в браузере. Сервер не нужен: страница собирает промпт из тех же пронумерованных цитат, что и `s`, и отдаёт его через буфер обмена. Сырой HTML из ответа показывается как текст, а ссылки открываются только по http(s) и mailto.

## Разработка

```sh
git clone https://github.com/DaniilMats/inline-notes
claude --plugin-dir ./inline-notes      # сессия с вашей рабочей копией
claude plugin test ./inline-notes       # тесты
claude plugin validate ./inline-notes   # манифесты и хуки — так, как их читает движок
```

Логика ревью — чистые переходы состояния в [`hooks/review.ts`](hooks/review.ts), арифметика раскладки — в [`hooks/layout.ts`](hooks/layout.ts). Обе покрыты [`tests/fb.test.ts`](tests/fb.test.ts). Страница для браузера — один самодостаточный файл [`web/review.html`](web/review.html).
